## Personal data

These source fields hold named individuals' details and are removed from all processed and web outputs: `applicant_name`, `csc_id` (CSC operators), `Mobileno`, `OPR` (Grama One operators), `NODAL_OFFI`, `Contact_No` (UPHC officers). The raw files still contain them, so `data/raw` must not be republished.

## Comparability warnings

- Layer dates differ by up to eight years, and many layers are undated. See the Vintage column.
- Customer Service Centre: 1,222 of 2,909 records share exact coordinates with another record, so they are flagged as duplicates. This may reflect several registrations at one place. The `app_stage` field is undocumented, so open status is unknown.
- Hyderabad bus stops: 514 records fall outside the bounding box and are itemised in `excluded_records.csv`.
- Hospitals (GHMC list, 2018): public and private are mixed, and one record is labelled as a toilet in its category field.
- Hyderabad slums: 27 blank names. Centroids computed by this project from polygons.

## Cross-checks performed

- Census PCA and C-16 totals match exactly: 84,95,492 (BBMP with outgrowths) and 69,93,262 (GHMC with outgrowths). `process.py` fails if they diverge.
- Slum-distance medians were reproduced by an independent brute-force calculation: 0.43 km and 0.41 km.
- Automated tests confirm that each layer's file count equals its registry count. Coordinates are copied from source files with no generated points.

## Link checks (4 November 2026)

61 cited URLs tested. 51 returned HTTP 200 in Python. Of the other 10, 8 returned 200 in Chrome. `gba.karnataka.gov.in/home` returned 404 on direct load, so the site links the root address instead. `bswmlclearit.com/citizen` reset the connection in both tools.
